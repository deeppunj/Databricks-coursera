# Databricks-coursera

## README

Welcome to the companion repository for my **Databricks course on Coursera**!

This repository contains **all the source code used in that course**, organized so you can follow along with each lesson, run the notebooks and scripts yourself, and experiment with the examples in your own Databricks workspace.

### What you'll find here

- **Notebooks** — the complete Databricks notebooks from the course lessons
- **Scripts** — standalone code samples and utilities referenced in the lectures
- **Data** — sample datasets and files used in the exercises
- **Exercises** — starter and solution code for hands-on practice

### How to use this repository

1. Clone or download this repository.
2. Import the notebooks into your Databricks workspace.
3. Follow along with the corresponding course modules on Coursera.

Happy learning!
